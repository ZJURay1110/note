    list 类型¶

    称为"动态数组"或 简称为"列表"

    1 list 的定义¶

    list 是 Python 中最基本、最常用的可变序列类型。它是一个可以存放任意类型对象的有序集合。

    Info

    在 Python 内部，list 是通过动态数组（Dynamic Array）实现的。这意味着它在内存中分配了一块连续的空间来存储指向对象的引用（指针）。

    1.1 核心特性¶

    • 可变性 (Mutability)：与 range 不同，list 创建后可以原地修改元素、增加或删除长度。
    • 异质性 (Heterogeneity)：同一个列表中可以同时包含整数、字符串、列表、甚至是函数等不同类型的对象。
    • 有序性 (Ordered)：元素按照插入顺序排列，支持通过索引（Index）访问。
    • 动态扩容：当列表空间不足时，Python 会自动申请更大的内存空间，这保证了末尾添加元素（append）的效率。

    2 列表的建增删查¶

    2.1 创建 (Creation)¶

    Warning

    这里逗号后面有一个空格！我们自己写的时候可以不带，但是打印出来的时候是存在空格的。

    • 直接创建：使用方括号 []。
    • 构造函数：list(iterable) 将其他可迭代对象转换为列表。
    • 列表推导式：[expression for item in iterable if condition]。
    # 1. 基础创建
empty_list = []
fruits = ["apple", "banana", "cherry"]

# 2. 构造函数
nums = list(range(5))  # [0, 1, 2, 3, 4]

# 3. 混合类型
mixed = [1, "GIS", [120.1, 30.2], True]

    2.2 列表推导式 (List Comprehensions)¶

    列表推导式提供了一种从序列或其他可迭代对象中快速创建列表的简洁方式。其核心逻辑是将循环和条件判断整合在一行方括号内：

    [expression for item in iterable if condition]

    组成部分 说明
    expression 最终存入新列表的元素形式（变量本身或计算结果）
    for item in iterable 迭代逻辑，指定数据源
    if condition （可选）过滤逻辑，只有满足条件的元素才会被处理 
    # 1. 基础转换
squares = [x**2 for x in range(10)] 

# 2. 带条件的过滤
even_squares = [x**2 for x in range(10) if x % 2 == 0]

# 3. 嵌套循环（笛卡尔积）
points = [(x, y) for x in range(3) for y in range(3)] 

# 4. 嵌入条件表达式 (将负数替换为 0)
nums = [1, -2, 3, -4, 5]
result = [x if x > 0 else 0 for x in nums if x % 4 != 0]

    内存安全：推导式 vs 生成器

    如果目标仅是遍历而不需要保留整个列表，请使用生成器表达式（将 [] 改为 ()）。

    • list_comp = [x for x in range(1000000)] —— 占用大量内存
    • gen_expr = (x for x in range(1000000)) —— 几乎不占内存 (\(O(1)\))

    2.3 增加与修改 (Addition & Modification)¶

    这是 list 与 range 或 tuple 最显著的区别。

    方法/操作 说明 返回值 拷贝/修改类型 复杂度
    l[i] = x 直接通过索引修改元素 None 原地修改 \(O(1)\)
    l += m 将可迭代对象 \(m\) 追加至末尾 修改后的原列表 原地修改 \(O(len(m))\)
    .append(x) 在列表末尾添加一个元素 None 原地修改 摊销 \(O(1)\)
    .extend(m) 将 \(m\) 的所有元素追加至末尾 None 原地修改 \(O(len(m))\)
    .insert(i, x) 在索引 \(i\) 处插入元素 \(x\) None 原地修改 \(O(n)\)
    .sort() 对列表进行原地排序 None 原地修改 \(O(n \log n)\)

    注意：原地修改 (In-place)

    .sort() 和 .reverse() 是原地修改方法。执行 a = my_list.sort() 会导致 a 的值为 None。

    2.4 删除 (Deletion)¶

    方法/操作 说明 返回值 拷贝/修改类型 复杂度
    del l[i] 根据索引删除指定元素 - 原地修改 \(O(n)\)
    del l[i:j] 根据切片删除一段元素 - 原地修改 \(O(n)\)
    .pop([i]) 移除并返回指定位置元素 被移除的元素值 原地修改 末尾 \(O(1)\) / 中间 \(O(n)\)
    .remove(x) 移除第一个值为 \(x\) 的元素 None 原地修改 \(O(n)\)
    .clear() 移除列表所有元素 None 原地修改 \(O(1)\)

    2.5 查找与成员检查 (Lookup)¶

    方法/操作 说明 返回值 拷贝/修改类型 复杂度
    l[i] 通过索引访问元素 值的引用 - \(O(1)\)
    l[i:j] 切片访问 新列表 浅拷贝 \(O(k)\)
    x in l 检查元素是否存在 布尔值 - \(O(n)\)
    .index(x) 返回第一个 \(x\) 的索引 整数 - \(O(n)\)
    .count(x) 统计元素 \(x\) 出现的次数 整数 - \(O(n)\)

    3 列表的复制与引用机制¶

    在处理列表复制时，需要严格区分引用与拷贝。

    3.1 b = a（赋值：引用传递）¶

    • 原理：a 和 b 指向内存中同一个地址。
    • 后果：改了 a，b 也会变。
    • 返回值：无。
    • 类型：引用传递。

    3.2 b = a[:] 或 b = a.copy()（浅拷贝）¶

    • 原理：创建一个新列表，并复制原列表中元素的引用。
    • 后果：修改 b 的基本元素不会影响 a。
    • 返回值：新列表。
    • 类型：浅拷贝。

    什么是“浅”拷贝？

    如果列表里嵌套了列表（复合对象），复制出来的“外壳”是新的，但“内部嵌套的对象”还是连在一起的：

    python a = [1, [2, 3]] b = a.copy() b[1].append(4)  
print(a)  
# 输出: [1, [2, 3, 4]] —— a 还是被影响了！

    4 切片赋值 (Slicing Assignment)¶

    列表支持通过切片一次性替换多个元素，甚至改变列表长度。

    nums = [1, 2, 3, 4, 5]
# 1. 替换切片内容
nums[1:4] = [20, 30]  # [1, 20, 30, 5]
# 2. 清空切片
nums[1:3] = []        # [1, 5]
# 3. 插入数据
nums[1:1] = [100]     # [1, 100, 5] (索引 1 处插入)

    5 内存机制与性能¶

    5.1 引用存储¶

    列表存储的是对象的引用（内存地址），而不是对象本身。因此，列表本身的大小与其包含的对象大小无关。

    5.2 摊销常数时间 (Amortized Constant Time)¶

    由于列表采用“超额分配”策略，.append() 在绝大多数情况下是 \(O(1)\) 的，只有在极少数触发内存重新分配时才是 \(O(n)\)。

    5.3 复杂度对比表¶

    操作 复杂度 性能提示
    **索引访问 L[i]** \(O(1)\) 极快
    **末尾添加 append** \(O(1)\) 推荐用法
    **头部插入 insert(0, x)** \(O(n)\) 慢！需要移动所有后续元素
    **包含检查 x in L** \(O(n)\) 元素越多，查询越慢（建议大数据量改用 set）

    注意事项¶

    1. 浅拷贝陷阱：使用 list2 = list1 只是创建了引用的别名。若需备份，请使用 .copy()。
    2. 避免遍历时删除：在 for 循环中直接 remove 会导致索引偏移。推荐做法：使用列表推导式生成新列表。

    3. nums = [x for x in nums if x > 0]

    4. 类型限制：虽然列表支持异质数据，但通常建议在同一个列表中存放同类型数据以保持 sort() 的稳定性。
