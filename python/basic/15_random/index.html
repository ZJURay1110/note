    内置标准库random¶

    1. 算法核心机制：伪随机性 (Pseudo-randomness)¶

    Python 的 random 模块实现基于 梅森旋转算法 (Mersenne Twister)，具体算法编号为 MT19937。

    • 定义：该模块生成的是伪随机数。其数值序列并非真正随机，而是由一个确定性的数学算法根据初始状态计算得出的序列。
    • 内部状态：MT19937 维护一个包含 624 个 32 位整数的状态向量。每次生成随机数时，算法会通过位运算改变状态向量并输出结果。
    • 确定性：给定相同的初始状态（种子），算法产出的数值序列是完全一致的。这保证了程序在调试与实验环境下的可重复性。
    • 周期性：其周期长度为 \(2^{19937} - 1\)，在常规计算规模下可视为不循环。

    2. 常用函数¶

    分类 函数 技术逻辑 返回值类型 数学区间
    状态控制 seed(a=None) 初始化伪随机数生成器 (PRNG) 的内部状态 None -
    浮点数生成 random() 基础均匀分布生成器 float \([0.0, 1.0)\)
    uniform(a, b) 线性缩放均匀分布 float \([a, b]\)
    整数生成 randint(a, b) 离散均匀分布 int \([a, b]\) (含端点)
    randrange(start, stop, step) 步长限制的离散分布 int \([start, stop)\)
    序列操作 choice(seq) 随机索引映射 元素引用 -
    sample(seq, k) 无放回随机抽样 list 长度为 \(k\)
    shuffle(seq) Fisher-Yates 原地重排 None -

    2.1 整数操作 (Integer Functions)¶

    这类函数主要用于生成离散的整数值。

    函数 说明 范围（数学表示） 备注
    randint(a, b) 生成随机整数 \([a, b]\) 包含端点 \(b\)。
    randrange(stop) 生成 \(0\) 到 \(stop\) 的整数 \([0, stop)\) 不含端点 \(stop\)。
    randrange(start, stop, step) 按步长生成随机数 \([start, stop)\) 比如 (0, 10, 2) 只会产生 0, 2, 4, 6, 8。

    2.2 浮点数/概率分布 (Floating-point Distributions)¶

    除了平均分布，这些函数在模拟自然现象或生成噪声时非常有用。

    函数 说明 范围/分布 常用场景
    random() 基础随机浮点数 \([0.0, 1.0)\) 最常用的基础种子。
    uniform(a, b) 指定范围浮点数 \([a, b]\) 均匀分布。
    gauss(mu, sigma) 高斯/正态分布 平均值 \(\mu\), 标准差 \(\sigma\) 模拟误差、自然界样本。
    triangular(low, high, mode) 三角分布 \([low, high]\) 在特定值（mode）附近概率更高。
    expovariate(lambd) 指数分布 \((0, \infty)\) 模拟排队时间、放射性衰变。

    2.3 序列操作 (Sequence Operations)¶

    这类函数不会生成“新”数字，而是对已有的列表（List）等序列进行“翻牌”。

    函数 说明 是否修改原序列 备注
    choice(seq) 随机抽取 1 个元素 否 如果序列为空会报 IndexError。
    choices(seq, weights=None, k=1) 有放回抽样（选 \(k\) 次） 否 可以设置 权重，让某些元素更易被选中。
    sample(seq, k) 无放回抽样（选 \(k\) 个） 否 抽出来的元素不会重复，常用于抽奖。
    shuffle(seq) 随机打乱顺序 是 直接在原列表上操作，不返回新列表。

    3. 数值生成逻辑拆解¶

    3.1 random() 的基石作用¶

    所有连续分布函数（如 uniform, gauss）底层均依赖 random()。它通过生成 53 位精度的随机整数并除以 \(2^{53}\) 来实现。

    3.2 边界处理¶

    • randint(a, b)：其逻辑等同于 randrange(a, b + 1)，是 Python 序列操作中少数采用闭区间定义的函数。
    • uniform(a, b)：根据公式 \(a + (b-a) \times random()\) 计算，结果可能包含 \(b\)（取决于浮点数舍入精度）。

    4. 序列与内存操作¶

    4.1 随机抽样规范¶

    • choice(seq)：通过 len(seq) 计算随机索引，返回该索引处对象的引用。时间复杂度 \(O(1)\)。
    • sample(population, k)：从总体中选取 \(k\) 个唯一位置的元素并返回新列表。原序列不受影响。时间复杂度为 \(O(k)\)。

    4.2 原地修改：shuffle(seq)¶

    shuffle 直接修改传入的可变序列（如 list），不创建新对象。 * 算法原理：采用 Fisher-Yates 算法，从后往前遍历序列，将当前元素与前面随机位置的元素交换。 * 复杂度：时间复杂度 \(O(n)\)，空间复杂度 \(O(1)\)。

    5. 状态初始化与复现 (Seed)¶

    seed(a=None) 用于初始化伪随机数生成器的内部状态。

    • 手动指定：执行 random.seed(x) 后，后续生成的随机序列将被锁定。
    • 自动初始化：若不显式指定种子，Python 默认调用操作系统的熵源（如 /dev/urandom）作为种子。若系统不可用随机源，则回退至系统当前时间戳。
    import random

# 固定种子以保证结果可复现
random.seed(1024)
print(random.random()) # 结果永远固定

    6. 内存表现与安全限制¶

    6.1 内存分配 (id)¶

    调用生成函数产出的数值对象，其内存行为遵循 Python 对象的通用规则。 * 驻留检查：若生成的整数位于 [-5, 256] 范围内，返回的是 Python 预创建对象的 id。 * 动态创建：超出此范围的数值，每次生成均会在堆内存开辟新空间，产生新的 id。

    6.2 密码学不安全性¶

    random 模块生成的数值具有可预测性。 * 泄露风险：一旦获取连续的 624 个生成结果，即可通过数学推导重建梅森旋转算法的内部状态向量，从而预测后续所有数值。 * 替代方案：对于密码生成、身份验证令牌等安全敏感场景，必须使用基于硬件随机源的 secrets 模块。

    6.3 性能参考¶

    • 梅森旋转算法在软件实现上极快，且内存占用极低（状态向量约 2.5KB）。
    • 在多线程环境下，random 模块共享同一生成器状态，并受内部锁保护以确保线程安全。
