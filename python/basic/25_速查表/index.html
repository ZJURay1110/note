    速查表¶

    1. list类型¶

    1.1 创增删改¶

    分类 方法 说明 拷贝/引用类型
    创建 list() 或 [] 创建列表 新对象
    增加 .append(x) 末尾添加 \(x\) 原地修改
    .extend(iterable) 末尾追加可迭代对象 原地修改
    .insert(i, x) 索引 \(i\) 处插入 \(x\) 原地修改
    list1 + list2 拼接列表 新对象
    复制 .copy() 或 list[:] 浅拷贝列表 浅拷贝
    删除 .remove(x) 删除首个 \(x\)（无则报错） 原地修改
    .pop([i]) 移除并返回索引 \(i\) 的元素 原地修改
    del list[i] 删除指定索引或切片元素 原地修改
    .clear() 清空列表 原地修改
    修改 list[i] = x 修改指定索引元素 原地修改
    list[start:end] = iterable 修改切片范围元素 原地修改

    1.2 查找¶

    分类 方法 说明 拷贝/引用类型
    查找 .index(x) 查找首个 \(x\) 索引（无则报错） 不修改
    .count(x) 统计 \(x\) 出现次数 不修改
    list[i] 获取索引 \(i\) 的元素 不修改
    list[start:end:step] 获取切片 浅拷贝
    x in list 判断 \(x\) 是否存在 不修改

    1.3 其他操作¶

    分类 方法 说明 拷贝/引用类型
    排序/反转 .sort() 原地排序（默认升序） 原地修改
    sorted(list) 返回排序副本 新对象
    .reverse() 原地反转 原地修改
    list[::-1] 或 reversed(list) 返回反转副本或迭代器 新对象
    计算 len(list) 获取元素个数 不修改
    max(list) / min(list) 获取最大 / 最小值 不修改
    sum(list) 元素求和 不修改

    2. string类型¶

    2.1 创增删改 (不可变)¶

    分类 方法 说明 拷贝/引用类型
    创建 str() 或 "" 创建字符串 新对象
    增加(拼接) s1 + s2 拼接字符串 新对象
    s * n 重复 \(n\) 次 新对象
    sep.join(iterable) 使用 sep 拼接字符串 新对象
    删除(去重) s.strip([chars]) 移除两端指定字符 新对象
    s.lstrip([chars]) / s.rstrip([chars]) 移除左侧 / 右侧字符 新对象
    修改(替换) s.replace(old, new[, count]) 替换子串 old 为 new 新对象
    s.lower() / s.upper() 转全小写 / 全大写 新对象
    s.capitalize() / s.title() 首字母 / 每个单词首字母大写 新对象
    s.zfill(width) 左侧补 0 至长度 width 新对象
    s.ljust(w) / s.rjust(w) / s.center(w) 左 / 右 / 居中对齐并填充 新对象

    2.2 查找¶

    分类 方法 说明 拷贝/引用类型
    查找 s.find(sub) / s.rfind(sub) 查找首个/最后 sub 索引（无则返回 -1） 不修改
    s.index(sub) / s.rindex(sub) 查找首个/最后 sub 索引（无则报错） 不修改
    s.count(sub) 统计 sub 出现次数 不修改
    sub in s 判断是否包含 sub 不修改
    s.startswith(prefix) 判断前缀 不修改
    s.endswith(suffix) 判断后缀 不修改

    2.3 其他操作¶

    分类 方法 说明 拷贝/引用类型
    分割 s.split([sep]) / s.rsplit([sep]) 从左/右按 sep 分割 新对象
    s.splitlines() 按行分割 新对象
    s.partition(sep) 按 sep 分割为三元组 新对象
    格式化 s.format(*args, **kwargs) 字符串格式化 新对象
    f"{var}" f-string 格式化 新对象
    判断 s.isalpha() / s.isdigit() 判断纯字母 / 纯数字 不修改
    s.isalnum() / s.isspace() 判断纯字母数字 / 纯空白 不修改
    计算 len(s) 获取字符数 不修改

    3. set类型¶

    3.1 创增删改¶

    分类 方法 说明 拷贝/引用类型
    创建 set() 创建集合（空集合需用 set()） 新对象
    增加 .add(x) 添加元素 \(x\) 原地修改
    .update(m) 合并可迭代对象 \(m\) 原地修改
    删除 .remove(x) 删除 \(x\)（无则报错） 原地修改
    .discard(x) 删除 \(x\)（无则静默） 原地修改
    .pop() 随机移除并返回元素 原地修改
    .clear() 清空集合 原地修改
    复制 .copy() 浅拷贝集合 浅拷贝

    3.2 查找与计算¶

    分类 方法 说明 拷贝/引用类型
    查找 x in s / x not in s 判断 \(x\) 是否存在 不修改
    集合运算 s1 & s2 或 s1.intersection(s2) 取交集 新对象
    s1 &#124; s2 或 s1.union(s2) 取并集 新对象
    s1 - s2 或 s1.difference(s2) 取差集 新对象
    s1 ^ s2 或 s1.symmetric_difference(s2) 取对称差集 新对象
    关系判断 s1 <= s2 或 s1.issubset(s2) 判断是否为子集 不修改
    s1 >= s2 或 s1.issuperset(s2) 判断是否为超集 不修改
    计算 len(s) 获取元素个数 不修改

    4. dict类型¶

    4.1 创增删改¶

    分类 方法 说明 拷贝/引用类型
    创建 dict() 或 {} 创建字典 新对象
    增加/修改 d[key] = value 新增或修改键值 原地修改
    .update(other) 合并字典 other 原地修改
    .setdefault(k, default) 获取键值（无则添加并返回 default） 原地修改
    删除 .pop(key[, default]) 移除 key 并返回值（无则报错） 原地修改
    .popitem() 移除最后插入的键值对 原地修改
    del d[key] 删除键值对（无则报错） 原地修改
    .clear() 清空字典 原地修改
    复制 .copy() 浅拷贝字典 浅拷贝

    4.2 查找与其他操作¶

    分类 方法 说明 拷贝/引用类型
    查找 d[key] 获取 key 对应值（无则报错） 不修改
    .get(key[, default]) 获取 key 对应值（无则返回 default） 不修改
    key in d 判断键是否存在 不修改
    视图 .keys() 获取键视图 不修改
    .values() 获取值视图 不修改
    .items() 获取键值对视图 不修改
    其他 dict.fromkeys(iterable, v) 用 iterable 创建新字典 新对象
    计算 len(d) 获取键值对个数 不修改
