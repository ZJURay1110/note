# 函数

*第一类对象 (First-class Object) 与 代码复用的核心*

---

## 1 函数的定义

函数是组织好的、可重复使用的、用来实现单一或相关联功能的代码段。在 Python 中，函数被视为**第一类对象**。

!!! info "第一类对象 (First-class Object)"
    这意味着函数可以像变量一样被操作：它可以被赋值给变量、作为参数传递给其他函数、或者作为其他函数的返回值。

### 1.1 核心特性

* **模块化 (Modularity)**：将复杂逻辑拆分为独立单元，提高代码可读性和可维护性。
* **参数传递 (Parameter Passing)**：支持多种参数模式（位置、关键字、默认、打包等）。
* **作用域 (Scope)**：遵循 **LEGB 规则**（Local -> Enclosing -> Global -> Built-in）。
* **内存特性**：函数在定义时被编译为字节码对象存储在内存中；调用时产生**栈帧 (Stack Frame)**。

接受你的反馈，上次的输出确实为了追求精简而压缩了核心信息。在 Python 中，`def` 的参数定义机制是其解释器中最复杂的解析规则之一，且 `lambda` 同样完整支持这些参数变体。


## 2 函数的定义方式

Python 提供了基于语句的显式定义（`def`）与基于表达式的匿名定义（`lambda`）。两者的核心区别在于语法级职责：`def` 负责构建复杂的结构化逻辑，而 `lambda` 专门用于交付微型的内联数据流管道。



### 2.1 def 语句：结构化与复合参数定义

在 `def` 签名中，参数的编写方式直接决定了调用时内存栈帧的传参校验规则。Python 解析器强制要求参数定义必须遵循一条**严格的从左到右的顺序链**：

> **签名声明的铁律顺序（不可逆转）：**
> `位置限定参数 (/)` $\rightarrow$ `标准位置/关键字参数` $\rightarrow$ `可变位置参数 (*args)` $\rightarrow$ `关键字限定参数 (* 或后置)` $\rightarrow$ `可变关键字参数 (**kwargs)`

!!! info
    **位置参数** `args` : positional arguments  
    **关键字参数** `kwargs` : keyword arguments


#### 2.1.1 参数定义形态汇总

| 参数形态 | 语法定义结构 | 调用示例 |
| -------- | ------------ | -------- |
| **普通标准参数<br>（必选位置参数）** | `def f(a, b)` | `f(1, 2)` ✔<br>`f(a=1, b=2)` ✔ |
| **位置限定参数** | `def f(a, b, /)` | `f(1, 2)` ✔<br>`f(a=1, b=2)` ✘ |
| **默认值参数** | `def f(a, b=10)` | `f(1)` → `b=10`<br>`f(1, 20)` → `b=20` |
| **可变位置参数** | `def f(*args)` | `f(1, 2, 3)` <br>→ `args = (1, 2, 3)` |
| **关键字限定参数** | `def f(*, a, b)` <br> `def f(*args, a, b)` | `f(a=1, b=2)` ✔<br>`f(1, 2)` ✘ |
| **可变关键字参数** | `def f(**kwargs)` | `f(x=1, y=2)` <br>→ `kwargs={'x':1,'y':2}` |

!!! warning
    - `/` 是纯位置限制，其左侧的参数只能位置传参  
    - `*` 是对序列类型进行拆包，拆成位置参数，了之后，所有无关键词的参数会被打包吸收，所以后面是关键字参数  
    - `**` 是对字典类型进行拆包，在函数种拆字典时，字典的key只能是string类型

#### 2.1.2 极限复合定义示例

以下展示一个同时融合了五种参数编写方式的极端合法定义。这种设计常见于高阶框架（如 Django, FastAPI）的底层基类中，用于实现无损的参数转发：

```python
def ultimate_signature(pos1, pos2, /, std1, std2="default", *args, kw_only1, kw_only2=True, **kwargs):
    """
    高度复合的参数定义模型
    - pos1, pos2: 只能位置传参
    - std1, std2: 可位置、可关键字传参
    - args: 接收多余的位置参数，打包为 tuple
    - kw_only1, kw_only2: 必须关键字传参
    - kwargs: 接收多余的关键字参数，打包为 dict
    """
    pass

# —— 正确调用示例：
ultimate_signature(
    1, 2,                          # 位置限定
    3, std2="custom",              # 标准参数
    4, 5, 6,                       # 可变位置 (被 args 捕获)
    kw_only1="must_named",         # 关键字限定 (kw_only2 采用默认值)
    extra_field="custom_val"       # 可变关键字 (被 kwargs 捕获)
)

# —— 错误调用示例（抛出 TypeError）：
# ultimate_signature(pos1=1, pos2=2, std1=3, kw_only1="named") # 错误：位置限定参数使用了关键字传参
# ultimate_signature(1, 2, 3, 4, 5, 6, "named")                # 错误：关键字限定参数使用了位置传参

```


### 2.2 lambda 表达式：匿名与微型定义

很多开发者误以为 `lambda` 只能定义最简单的单参数映射（如 `lambda x: x+1`），但实际上，**`lambda` 完美支持上述除了类型提示之外的所有参数编写方式**。

#### 2.2.1 lambda 参数形态变体表

| 传参场景 | 编写方式语法示例 | 实际应用与解包机制 |
| --- | --- | --- |
| **无参数** | `lambda: "静态常数"` | 常用于回调函数初始化，或者需要延迟计算（Lazy Evaluation）的场景。 |
| **多参数与默认值** | `lambda x, y=10, z=100: x + y + z` | 同样遵循默认值在定义期绑定的特征，右侧表达式可直接引用。 |
| **动态复合参数** | `lambda *args, **kwargs: (args, kwargs)` | 完美支持可变参数打包，常用于编写通用的代理、拦截器或动态装饰器。 |
| **位置/关键字限定** | `lambda x, /, *, y: x * y` | 同样支持 `/` 与 `*` 分隔符，严密限制匿名函数的调用边界。 |

```python
# 1. 动态闭包中的默认值绑定
funcs = [lambda x, power=i: x ** power for i in range(3)]
# funcs[2](5) —— 实际执行的是 5 ** 2 = 25

# 2. 结合高阶函数的复杂解包
data = [(1, "apple"), (2, "banana"), (3, "cherry")]
# 仅根据元组中第二个元素的最后一个字母进行逆序排列
data.sort(key=lambda item, /, *, reverse_target=True: item[1][-1])

# 3. 接收任意参数并转发的微型代理
logger_proxy = lambda *args, prefix="[LOG]", **kwargs: print(prefix, args, kwargs)
# logger_proxy("Data sent", status=200) # 输出: [LOG] ('Data sent',) {'status': 200}

```

> **内存性能防坑**：无论是 `def` 还是 `lambda`，定义含有默认参数的函数时，默认值对象都在**执行到该定义语句时一次性求值**并固化。若默认值为可变对象（如列表），每次调用时使用的都是同一个内存堆地址。

## 3 返回值 (Return Value)

函数通过 `return` 语句结束执行并返回结果。

| 返回情况 | 说明 | 返回值 | 拷贝/引用类型 |
| --- | --- | --- | --- |
| **无 return** | 函数执行完毕自动结束 | `None` | - |
| **单个值** | 返回一个指定对象 | 对象本身 | **引用传递** |
| **多个值** | `return a, b` | 打包后的 **tuple** | **引用传递** |

```python
def get_point():
    return 10, 20  # 实际返回的是 (10, 20)

x, y = get_point() # 利用解包直接获取

```

## 4 常用函数操作汇总表

| 分类 | 方法/操作 | 说明 | 返回值 | 拷贝/修改类型 | 复杂度 |
| --- | --- | --- | --- | --- | --- |
| **调用** | `f(*args, **kwargs)` | 执行函数逻辑 | 设定的 `return` 值 | **引用传递** (参数/结果) | 取决于逻辑 |
| **匿名函数** | `lambda x: x*2` | 定义短小的内联函数 | 函数对象 | **引用传递** | $O(1)$ |
| **高阶函数** | `map(f, iterable)` | 对序列每个元素应用函数 | **迭代器 (map object)** | - | $O(n)$ |
|  | `filter(f, iterable)` | 根据函数筛选元素 | **迭代器 (filter object)** | - | $O(n)$ |
| **自省** | `callable(obj)` | 检查对象是否可被调用 | 布尔值 | - | $O(1)$ |



## 5 内存机制与作用域

### 5.1 参数传递

Python 严格意义上是 **“对象引用传递” (Pass by object reference)**。

* 如果你传递的是**不可变对象**（int, str, tuple），在函数内部修改它会产生新对象，不影响外部。
* 如果你传递的是**可变对象**（list, dict, set），在函数内进行**原地修改**，外部变量会随之改变。

### 5.2 作用域复杂度表

| 变量类型 | 修改方式 | 影响范围 | 复杂度 |
| --- | --- | --- | --- |
| **局部变量 (Local)** | 直接赋值 | 仅限函数内部 | $O(1)$ |
| **全局变量 (Global)** | 需声明 `global` | 整个模块 | $O(1)$ |
| **闭包变量 (Enclosing)** | 需声明 `nonlocal` | 外部嵌套函数 | $O(1)$ |



## 注意事项

1. **函数名即引用**：`f2 = f1` 会让 `f2` 也指向 `f1` 的代码块，这属于**引用传递**。
2. **Lambda 的局限性**：只能包含一个表达式，不能有复杂的 `if-else` 或循环。
3. **递归深度**：Python 默认限制递归深度（通常是 1000），防止栈溢出。大规模数据处理应考虑循环。
4. **文档字符串 (Docstrings)**：推荐在函数开头使用 `"""说明文字"""`，以便通过 `help(func)` 或 `func.__doc__` 查看用法。
