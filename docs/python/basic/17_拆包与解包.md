# 解包运算符

*数据的解构与重组 (Unpacking & Packing)*

---

## 1 运算符定义

在 Python 中，星号（`*`）和双星号（`**`）被称为解包（Unpacking）运算符。它们的作用是将容器（如列表、元组、字典）中的元素“拆解”出来，或者在函数定义中将多个参数“打包”进去。

!!! info
    解包运算符本质上是迭代协议的扩展。`*` 作用于所有**可迭代对象 (Iterables)**，而 `**` 专用于**映射对象 (Mappings/Dictionaries)**。

### 1.1 核心操作逻辑

* **解包 (Unpacking)**：将集合中的元素拆分为独立的个体。
* **打包 (Packing)**：将多个独立的个体收集到一个容器中（通常用于函数参数）。


## 2 单星号 `*`：迭代对象解包

`*` 运算符可以应用于列表、元组、集合、字符串等序列。

### 2.1 序列合并与创建

通过 `*` 可以非常高效地将多个序列合并。

```python
# 1. 列表合并
list1 = [1, 2]
list2 = [3, 4]
combined = [*list1, *list2, 5]  # [1, 2, 3, 4, 5]

# 2. 字符串拆解
chars = [* "ABC"]  # ['A', 'B', 'C']

```

### 2.2 扩展赋值解包 (Extended Iterable Unpacking)

用于将序列的一部分赋值给变量，剩下的部分“打包”给一个列表。

```python
# 获取首尾，中间打包
first, *middle, last = [1, 2, 3, 4, 5]
# first=1, last=5, middle=[2, 3, 4]

```

### 2.3 函数调用中的解包

将列表或元组中的元素作为独立的位置参数传递给函数。

```python
def func(a, b, c):
    return a + b + c

nums = [1, 2, 3]
print(func(*nums))  # 等价于 func(1, 2, 3)

```


## 3 双星号 `**`：字典解包

`**` 专门处理键值对数据，主要用于字典的合并与命名参数传递。

### 3.1 字典合并 (Python 3.5+)

!!! warning "键冲突规则"
    在字典合并时，如果存在重复的键，**后者会覆盖前者**。

```python
d1 = {"name": "Alice", "age": 20}
d2 = {"age": 25, "city": "NY"}

# 合并字典
merged = {**d1, **d2} 
# 结果: {'name': 'Alice', 'age': 25, 'city': 'NY'}

```

### 3.2 函数调用中的解包

将字典的键值对转化为函数的关键字参数（Keyword Arguments）。

```python
def greet(name, age):
    print(f"{name} is {age}")

info = {"name": "Bob", "age": 30}
greet(**info)  # 等价于 greet(name="Bob", age=30)

```



## 4 函数定义中的打包 (`*args` & `kwargs`)

当不确定函数会接收多少个参数时，在形参中使用运算符。

| 形式 | 名称约定 | 说明 | 容器类型 |
| --- | --- | --- | --- |
| **`*args`** | Positional Arguments | 收集多余的位置参数 | **tuple (元组)** |
| **`**kwargs`** | Keyword Arguments | 收集多余的关键字参数 | **dict (字典)** |

```python
def super_func(*args, **kwargs):
    print(args)    # 所有的位置参数打包成元组
    print(kwargs)  # 所有的关键字参数打包成字典

super_func(1, 2, a=3, b=4)
# 输出: (1, 2) 和 {'a': 3, 'b': 4}
```


## 5 操作汇总表

| 操作场景 | 语法 | 说明 | 返回值 | 修改类型 | 复杂度 |
| --- | --- | --- | --- | --- | --- |
| **序列合并** | `[*a, *b]` | 展开多个序列 | **新列表** | **浅拷贝** | $O(n+m)$ |
| **字典合并** | `{**d1, **d2}` | 展开多个字典 | **新字典** | **浅拷贝** | $O(n+m)$ |
| **赋值解包** | `a, *b = seq` | 收集剩余元素 | **列表 (b)** | **浅拷贝** | $O(n)$ |
| **函数传参** | `f(*args)` | 序列转位置参数 | - | **引用传递** | $O(n)$ |
| **函数传参** | `f(**kwargs)` | 字典转关键字参数 | - | **引用传递** | $O(n)$ |



## 6 内存机制与注意事项

### 6.1 浅拷贝 (Shallow Copy)

使用 `[*l]` 或 `{d}` 创建新容器时，内部嵌套的可变对象（如列表中的列表）仍然是**引用传递**。

### 6.2 运算符限制

1. **位置限制**：在函数定义中，`*args` 必须在 `kwargs` 之前。
2. **解包次数**：在 Python 3.5+ 之后，同一个表达式中允许使用多次 `*` 或 ``。
3. **唯一性**：解包赋值（如 `a, *b, *c = seq`）在同一层级只能出现**一个** `*` 变量，否则 Python 无法确定如何分配剩余元素。

!!! warning "语法错误"
    `d` 不能在容器（如 `{}` 或函数括号）外部单独使用。
      * `x = d` —— **错误 (SyntaxError)**
      * `x = {d}` —— **正确**
