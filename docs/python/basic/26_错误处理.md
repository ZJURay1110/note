# 错误处理



```try:
    num = int(input("请输入数字: "))
    result = 10 / num
except ZeroDivisionError:
    print("不能除以零！")
except ValueError:
    print("请输入有效数字！")
else:
    print(f"结果是: {result}")  # 没有异常时执行
finally:
    print("程序运行完毕")  # 始终执行
```



```
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为零！")  # 主动抛出异常
    return a / b

try:
    divide(10, 0)
except ValueError as e:
    print(f"捕获到异常: {e}")

```

异常类型	说明  
ZeroDivisionError	除以零  
ValueError	值错误（如 int("abc")）  
TypeError	类型错误（如 1 + "2"）  
IndexError	索引超出范围  
KeyError	字典键不存在  
FileNotFoundError	文件不存在  
AttributeError	对象没有该属性  







TypeError：类型用错了（"不该用这种类型"）  
ValueError：类型对了，但值不合法（"值不对"）




```
 TypeError - 类型不对
int("123")      # ✅ 没问题，字符串内容是数字
int("abc")      # ❌ ValueError: 类型是 str，但值 'abc' 不是合法数字

 但如果是这样：
"123" + 456     # ❌ TypeError: str 和 int 不能相加（类型冲突）
```
