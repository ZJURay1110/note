# tuple 类型

*不可变的序列类型 (Immutable Sequence)*

---

## 1 tuple 的定义

`tuple`（元组）是 Python 中的核心序列类型，它存储的是**有序**且**不可变**的对象集合。一旦创建，其内部元素的引用地址不可更改。

!!! info
    在 Python 内部，`tuple` 是通过**常量数组**实现的。由于其长度固定且内容不可变，Python 可以在内存分配和访问速度上对其进行深度优化，使其性能优于 `list`。

### 1.1 核心特性

* **不可变性 (Immutability)**：元组一旦声明，不能增加、删除或修改元素。这使其在多线程环境下具有天然的安全性。
* **有序性 (Ordered)**：元素按照插入顺序排列，支持通过索引（Index）和切片（Slicing）访问。
* **可哈希性 (Hashable)**：如果元组内所有元素都是不可变的，则该元组可作为字典的键或集合的元素。
* **结构的稳定性**：通常用于存储具有结构意义的数据（如经纬度 `(lat, lon)` 或数据库返回的行记录）。

## 2 元组的建增删查

### 2.1 创建 (Creation)

!!! warning "单元素元组"
    定义只包含一个元素的元组时，必须在元素后加上**逗号**，否则 Python 会将其识别为普通的括号运算符。

* `t = (1)` —— 类型为 `int`
* `t = (1,)` —— 类型为 `tuple`

* **直接创建**：使用圆括号 `()`。
* **构造函数**：`tuple(iterable)`。
* **隐式创建（打包）**：不使用括号，直接用逗号分隔。

```python
# 1. 构造函数
t1 = tuple([1, 2, 3])

# 2. 隐式打包 (Packing)
point = 10, 20  # 等价于 (10, 20)

# 3. 解包 (Unpacking)
x, y = point  # x=10, y=20

```

## 2.2 增加与修改 (Addition & Modification)

由于元组具有**不可变性**，它不支持任何“原地修改”操作。所有的“增改”操作本质上都是创建了**新元组**。

| 分类 | 方法/操作 | 说明 | 返回值 | 拷贝/引用类型 |
| --- | --- | --- | --- | --- |
| **合并** | `t1 + t2` | 连接两个元组 | **新元组** | **浅拷贝** |
| **重复** | `t * n` | 将元组内容重复 $n$ 次 | **新元组** | **浅拷贝** |
| **扩展解包** | `(*t1, *t2)` | Python 3.5+ 提供的解包合并方式 | **新元组** | **浅拷贝** |

!!! info "“相对”不可变性"
    元组本身存储的引用不可变，但如果元组包含**可变对象**（如列表），则该列表的内容是可以修改的。

```py
python t = (1, [2, 3]) t[1].append(4)
# 成功：t 变为 (1, [2, 3, 4])，但元组引用的地址未变
```

## 2.3 删除 (Deletion)

元组不支持删除其中的单个元素。

| 方法 | 说明 | 返回值 | 状态 |
| --- | --- | --- | --- |
| **`del t`** | 删除整个元组变量 | - | 释放引用 |
| **`del t[0]`** | 尝试删除单个元素 | - | **报错 `TypeError**` |

## 2.4 查找与成员检查 (Lookup)

元组支持高效的索引访问，但由于是线性结构，值搜索的性能随数据量增长。

| 分类 | 方法/操作 | 说明 | 返回值 | 复杂度 |
| --- | --- | --- | --- | --- |
| **索引访问** | `t[i]` | 获取指定位置的元素 | 元素引用 | $O(1)$ |
| **切片** | `t[i:j]` | 获取范围内的子元组 | **浅拷贝新元组** | $O(k)$ |
| **计数** | `.count(x)` | 统计元素 $x$ 出现的次数 | 整数 | $O(n)$ |
| **定位** | `.index(x)` | 查找第一个 $x$ 的索引 | 整数 | $O(n)$ |
| **成员检查** | `x in t` | 检查 $x$ 是否存在于元组中 | 布尔值 | $O(n)$ |

## 3 内存机制与性能

### 3.1 复杂度对比表

| 操作 | 复杂度 | 性能提示 |
| --- | --- | --- |
| **索引访问`t[i]`** | $O(1)$ | 极快，且内存开销比列表更小 |
| **创建/复制** | $O(n)$ | 涉及内存申请与引用复制 |
| **迭代遍历** | $O(n)$ | 性能略高于列表 |

### 3.2 性能优势

1. **资源开销**：`list` 为了实现动态扩容会预分配额外空间；`tuple` 内存分配是精确且固定的。
2. **常量优化**：Python 内部会对一些小元组进行缓存和复用。

## 4 tuple 的其他函数与方法

### 4.1 函数 (Built-in Functions)

这些函数常用于处理元组的整体统计和转换。

| 函数 | 说明 | 返回值 |
| --- | --- | --- |
| **`len(t)`** | 获取元组元素总数 | 整数 |
| **`max(t)`** | 获取元组中的最大元素（需类型一致） | 元素 |
| **`min(t)`** | 获取元组中的最小元素 | 元素 |
| **`sum(t)`** | 对数值型元组求和 | 数值 |
| **`sorted(t)`** | 对元组元素进行排序 | **浅拷贝新列表** |

```python
data = (5, 2, 8, 1)
sorted_list = sorted(data)  # [1, 2, 5, 8]

```

### 4.2 方法 (Instance Methods)

虽然元组的方法很少，但配合 Python 的内置函数可以实现强大的功能。

#### 4.2.1 `reversed()` 迭代

```python
t = (1, 2, 3)
for i in reversed(t):
    print(i) # 输出 3, 2, 1 (返回的是迭代器，不产生新元组)

```

#### 4.2.2 命名元组 (Advanced)

!!! info "进阶提示：collections.namedtuple"
    当你需要像访问对象属性一样访问元组时，可以使用 `namedtuple`。

```python
    from collections import namedtuple
    Point = namedtuple('Point', ['x', 'y'])
    p = Point(11, y=22)
    print(p.x)  # 11
```
