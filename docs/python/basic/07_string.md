# 字符串


---
字符串是 Python 中最常用的数据类型，用于存储文本。  

!!! warning 
    它是**不可变序列**（Immutable），意味着一旦创建，就不能修改其中的某个字符。

### 1.1 引号表示法

* 单引号 (`'...'`) 或 双引号 (`"..."`)：两者等价，通常用于单行字符串。
* 三引号 (`'''...'''` 或 `"""..."""`)：用于表示**多行字符串**，且会保留字符串内的换行符和空格。


**示例**  
```py
print("""hi
i am
Lee
 Ray""")

"""输出
hi
i am
Lee
 Ray
"""

print("hi i\nam Ray \n Lee")

""" 输出
hi i
am Ray 
 Lee
"""

```


### 1.2 **转义字符**

使用反斜杠 `\` 表示特殊含义（如 `\n` 换行，`\t` 制表符，`\\` 表示反斜杠本身）。  

在 Python 字符串中，除了常见的 `\n`（换行）和 `\t`（制表符），我们还可以直接使用**八进制**或**十六进制**数值来表示任何字符。这在处理不可见字符、特殊符号或二进制数据时非常有用。  
通过进制表示法，我们可以直接通过字符的 **ASCII 码** 或 **Unicode 码** 来输入字符。

#### A. 八进制表示法 (`\ooo`)
* **语法**：`\` + **1 到 3 位**八进制数字（0-7）。
* **范围**：`\0` 到 `\377`（即十进制的 0-255）。
* **示例**：
    * `\141` -> 对应十进制 97 -> 字符 `'a'`
    * `\101` -> 对应十进制 65 -> 字符 `'A'`

#### B. 十六进制表示法 (`\xhh`)
* **语法**：`\x` + **2 位**十六进制数字（0-9, a-f）。
* **范围**：`\x00` 到 `\xff`（即十进制的 0-255）。
* **示例**：
    * `\x61` -> 对应十进制 97 -> 字符 `'a'`
    * `\x41` -> 对应十进制 65 -> 字符 `'A'`

#### C. Unicode 表示法（十六进制进阶）
如果需要表示超出 ASCII 范围的字符（如中文或表情符号），需要用到 Unicode 专用转义：
* **`\uhhhh`**：4 位十六进制（基本多语言平面）。
* **`\Uhhhhhhhh`**：8 位十六进制（全部 Unicode 字符）。


#### 快速对比表

| 字符 | 十进制 (ASCII) | **八进制 (`\ooo`)** | **十六进制 (`\xhh`)** |
| :--- | :--- | :--- | :--- |
| **空格** | 32 | `\040` | `\x20` |
| **A** | 65 | `\101` | `\x41` |
| **a** | 97 | `\141` | `\x61` |
| **!** | 33 | `\041` | `\x21` |



#### 注意事项

1.  **不要混淆前缀**：
    * 在定义**数字变量**时，八进制用 `0o`（如 `num = 0o10`）。
    * 在**字符串转义**时，八进制只用 `\`（如 `s = "\110"`）。**千万别写成 `\0o110`**，这会被识别为字符 `\0`（空字符）后面跟着字符串 `"o110"`。

2.  **位数限制**：
    * `\x` 后面**必须紧跟 2 位**十六进制数。如果写 `\x6` 会报错。
    * 八进制最多 3 位，如果写 `\400`，因为它超过了 255（八进制 377），Python 可能会报错或产生非预期字符。

3.  **可读性**：
    * 除非你在写加密算法、处理二进制流或者在写那种“不让别人一眼看懂”的代码，否则建议直接写字符 `'a'` 而不是 `\x61`。

**代码示例：**
```python
# 不同的写法，同样的结果
print("Hello")      # 普通写法
print("\110\145\154\154\157")  # 八进制
print("\x48\x65\x6c\x6c\x6f")  # 十六进制

# Unicode 示例
print("\u4f60\u597d")  # 输出：你好
```




### 1.3 原始字符串 (Raw String)

在引号前加 `r`，使转义字符失效。常用于正则表达式或文件路径（如 `r"C:\Users\name"`）。


### 1.4 索引与切片
* 索引从 `0` 开始，末尾从 `-1` 开始。
* 切片语法：`s[start:stop:step]`（左闭右开区间）。




## 2 字符串相关函数

### 2.1 内置函数
这些函数可以直接对字符串对象进行操作。

| 函数 | 功能描述 | 示例 |
| :--- | :--- | :--- |
| **`len(s)`** | 返回字符串的长度（字符个数） | `len("Python")` -> `6` |
| **`str(x)`** | 将其他类型转换为字符串 | `str(123)` -> `"123"` |
| **`ord(c)`** | 返回单个字符对应的 Unicode 码 | `ord('A')` -> `65` |
| **`chr(i)`** | 返回 Unicode 码对应的字符 | `chr(65)` -> `'A'` |
| **`max(s)` / `min(s)`** | 返回字符串中 ASCII 码最大/最小的字符 | `max("abc")` -> `'c'` |



### 2.2 常用字符串方法 (无需 import)
这些方法直接作用于字符串对象 `s`，调用格式为 `s.method()`。

| 类别 | 方法 | 功能描述 |   示例  |
| :--- | :--- | :--- | :--- |
| **大小写** | `lower()` / `upper()` | 全部转为小写/大写 | `"Py".lower()` -> `"py"` |
| | `swapcase()` | 大小写互换 | `"AbC".swapcase()` -> `"aBc"` |
| **判断** | `isdigit()` | 是否全为数字 | `"123".isdigit()` -> `True` |
| | `isalpha()` | 是否全为字母 | `"A1".isalpha()` -> `False` |
| |`count(sub[,start[,end]])`|判断子串的出现次数|`s.count("Hello")` ||
| | `startswith(prefix)` | 是否以指定前缀开头 | `s.startswith("Hello")` |
| **查找替换** | `find(sub[,start[,end]])` | 查找子串索引，找不到返回 `-1` | `"abc".find("b")` -> `1` |
| | `replace(old, new)` | 替换所有匹配的子串 | `"aa".replace("a", "b")` -> `"bb"` |
| **拆分合并** | `split(sep)` | 按分隔符拆分成列表 | `"a,b".split(",")` -> `['a', 'b']` |
| | `join(iterable)` | 将序列元素连接成字符串 | `"-".join(["A", "B"])` -> `"A-B"` |
| **修剪填充** | `strip()` | 移除首尾空格或指定字符 | `"  x  ".strip()` -> `"x"` |
| | `center(width, fill)` | 居中并在两侧填充 | `"Hi".center(6, "*")` -> `"**Hi**"` |




### 2.3 相关标准库 (需使用 import)

当内置方法不够用时，Python 提供了功能强大的标准库。

#### A. `string` 模块：预定义的字符集合
这个库主要提供了一些常用的字符常量，省得你自己去手写所有的字母或数字。

```python
import string

print(string.ascii_letters)   # 所有字母 (a-z, A-Z)
print(string.digits)          # 所有数字 (0-9)
print(string.punctuation)     # 所有标点符号
print(string.hexdigits)       # 十六进制字符 (0-9, a-f, A-F)

# 用处示例：生成一个随机验证码
import random
code = "".join(random.sample(string.ascii_letters + string.digits, 6))
```

#### B. `re` 模块：正则表达式 (高阶字符串处理)
如果你要处理复杂的匹配（比如验证邮箱、手机号、提取网页标题），`re` 是必杀技。

* **`re.search(pattern, string)`**: 扫描整个字符串并返回第一个成功的匹配。
* **`re.findall(pattern, string)`**: 找出所有匹配的内容，以列表形式返回。
* **`re.sub(pattern, repl, string)`**: 利用正则规则进行替换。

```python
import re

text = "我的电话是 138-1234-5678，他的电话是 139-8765-4321"
# 匹配电话号码模式：3位数字-4位数字-4位数字
phones = re.findall(r'\d{3}-\d{4}-\d{4}', text)
print(phones)  # ['138-1234-5678', '139-8765-4321']
```



#### C. `textwrap` 模块：文本排版
用于美化长文本的输出，比如自动换行、控制缩进。

```python
import textwrap

long_text = "Python 是一种解释型、面向对象、动态数据类型的高级程序设计语言..."
# 将长文本限制在每行 20 个字符
print(textwrap.fill(long_text, width=20))
```



## 3 字符串输出

Python 提供了多种将变量嵌入字符串并输出的方式：

### 3.1 格式化输出 (f-string) —— **推荐使用**
Python 3.6+ 引入，语法最简洁，性能最高。
```python
name = "Python"
version = 3.12
print(f"欢迎来到 {name} {version} 的世界！")
```

### 3.2 `format()` 方法
功能最强大，支持复杂的对齐和填充。
```python
# 按照位置或关键字填充
print("坐标：({x}, {y})".format(x=10, y=20))

# 数字格式化：保留两位小数
print("π 的值约为：{:.2f}".format(3.1415926))

"""输出
坐标：(10, 20)
π 的值约为：3.14
"""
```

### 3.3 `%` 占位符 (旧式格式化)
类似于 C 语言的 `printf`。
* `%s`：字符串
* `%d`：整数
* `%f`：浮点数
```python
print("Hello,ppp%sqqqYou are %d years old." %("小明", 18))
#Hello,ppp小明qqqYou are 18 years old.
```




## 注意事项
1.  **不可变性**：不能执行 `s[0] = 'A'`。若要修改，必须生成新字符串（如使用 `replace` 或切片拼接），语句 `s.replace('is', 'eez')` 不会直接修改原始字符串 s 的内容，而是返回一个字符串，可以写`a=s.replace('is', 'eez')` 。
2.  **字符串拼接**：少量拼接用 `+`，但在循环内大量拼接建议使用 `''.join(list)`，效率更高。
3.  **空字符串**：`""` 的长度为 `0`，且在布尔判断中被视为 `False`。
4.  **编码**：Python 3 默认使用 **UTF-8** 编码，支持直接在字符串中使用中文。
