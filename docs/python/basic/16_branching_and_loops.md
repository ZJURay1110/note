# 分支与循环

---

## 1 分支

在 Python 中，分支结构通过逻辑判断决定代码的执行路径。其本质是**对表达式布尔值的评估与指令跳转**。

### 1.1 `if-elif-else` 结构
Python 采用强制缩进定义代码块，分支逻辑遵循顺序求值原则：
* **顺序评估**：解释器从上至下依次计算表达式的布尔值，一旦某个条件为 `True`，则执行对应代码块并跳出整个分支结构。
* **互斥性**：在一个完整的 `if-elif-else` 结构中，仅有一个分支（或都不执行）会被触发。

### 1.2 对象的布尔值 (Truthiness)

!!! info "隐式类型转换"
    在分支判断中，Python 会自动调用对象的 `__bool__()` 或 `__len__()` 方法。

以下对象在逻辑判断中被评估为 `False`：
* **常量**：`None`, `False`
* **数值零**：`0`, `0.0`, `0j`
* **空容器**：`''`, `()`, `[]`, `{}`, `set()`, `range(0)`

### 1.3 短路求值 (Short-circuit Evaluation)
* **`and` 逻辑**：从左到右计算，若遇到 `False` 则立即停止并返回该值，不再计算后续表达式。
* **`or` 逻辑**：从左到右计算，若遇到 `True` 则立即停止并返回该值。



## 2 循环

循环结构用于重复执行代码块。Python 提供了基于迭代协议的 `for` 和基于条件判定的 `while`。

### 2.1 `for` 循环
Python 的 `for` 循环本质上是**迭代器协议 (Iterator Protocol)** 的高级封装。

**底层执行流程：**
1. 调用被迭代对象的 `__iter__()` 获取迭代器（Iterator）。
2. 循环调用迭代器的 `__next__()` 获取元素。
3. 捕获 `StopIteration` 异常，此时循环正常终止。

```python
# 示例：遍历序列
nums = [10, 20, 30]
for x in nums:
    print(x)
```



### 2.2 `while` 循环
`while` 循环是基于**条件表达式**的重复控制结构。

* **逻辑流程**：每次循环开始前，计算条件表达式。若为 `True` 则执行循环体；若为 `False` 则终止。
* **安全性**：必须确保循环体内存在改变条件布尔值的逻辑，否则会导致进程死循环。

```python
count = 0
while count < 3:
    print(count)
    count += 1
```

### 2.3 与 `else` 连用

!!! tip "逻辑关键点"
    循环后的 `else` 块**只有在循环正常结束时执行**。如果循环是被 `break` 强行终止的，则不执行 `else`。  
    换句话说，只有`break`，才能打断`else`

| 场景 | `else` 代码块执行情况 |
| :--- | :--- |
| **`for` 遍历完所有元素** | 执行 |
| **`while` 条件变为 `False`** | 执行 |
| **触发 `break` 跳出** | **不执行** |
| **触发 `continue`** | 执行（不影响最终遍历完成） |

**搜索场景应用示例：**
```python
target = 7
nums = [1, 3, 5]

for n in nums:
    if n == target:
        print("找到了")
        break
else:
    # 只有当全部找完都没 break 时，才会执行这里
    print("目标不存在")
```



### 2.4 跳转指令对照表

| 指令 | 动作 | 影响 |
| :--- | :--- | :--- |
| **`break`** | 立即终止当前最内层循环 | 跳过循环对应的 `else` |
| **`continue`** | 立即跳过本次循环剩余代码 | 进入下一轮条件判定/迭代 |
| **`pass`** | 空操作占位 | 无（仅用于维持语法结构完整） |




!!! warning
    ### 注意事项

1. 下面两句话是真的：  
    break用来跳出最内层for或while循环，退出该循环后程序从循环代码后继续执行； continue用来结束当前当次循环。
    在循环中break语句的作用是跳出当前循环。
