# dict 类型

*由键值对组成的映射序列类型*

---

## 1 dict 的定义

`dict` 是 Python 中的核心数据类型，它存储的是**键值对 (Key-Value pairs)** 的映射关系。每个键指向一个特定的值。

!!! info
    在 Python 内部，`dict` 与 `set` 一样基于**哈希表 (Hash Table)** 实现。从 Python 3.7 开始（并在 Python 3.8 成为语言标准），字典正式保证了**插入顺序 (Insertion Order)**，即遍历字典时，元素出现的顺序与插入顺序一致。

### 1.1 核心特性

* **键的唯一性 (Unique Keys)**：同一个字典中，键必须唯一。如果重复赋值，旧值将被新值覆盖。
* **键必须可哈希 (Hashable)**：键必须是不可变对象（数字、字符串、元组）。列表、集合或另一个字典不能作为键。
* **值的异质性 (Heterogeneity)**：值 (Value) 可以是任何 Python 对象，且允许重复。
* **快速检索**：通过键访问值的平均时间复杂度为 $O(1)$，与字典规模无关。


## 2 字典的建增删查

### 2.1 创建 (Creation)

!!! warning "空字典定义"
    使用 `{}` 默认创建的是空字典。  
    字典不能用`dict*n`

* **直接创建**：使用 `{key: value}` 格式。
* **构造函数**：`dict()`。
* **字典推导式**：`{k_expr: v_expr for item in iterable}`。

```python
# 1. 构造函数
d1 = dict(name="Gemini", version=2.0)

# 2. 列表转字典
pairs = [("A", 1), ("B", 2)]
d2 = dict(pairs)

# 3. 字典推导式：生成数字及其平方的映射
squares = {x: x**2 for x in range(5)} # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
```


## 2.2 增加与修改 (Addition & Modification)

字典通过键进行定位，如果键不存在则为增加，如果键已存在则为修改。

| 分类 | 方法/操作 | 说明 | 返回值 | 拷贝/引用类型 |
| :--- | :--- | :--- | :--- | :--- |
| **基础操作** | `d[key] = value` | 插入或更新键值对 | `None` | 原地修改 |
| **合并** | `.update(m)` | 合并另一个字典或可迭代键值对 | `None` | 原地修改 |
| | `d1 \| d2` | Python 3.9+ 提供的合并运算符 | **新字典** | **浅拷贝** |
| **复制** | `d2 = d1` | 变量引用指向同一地址 | - | **引用传递** |
| | `.copy()` | 创建字典的浅副本 | **新字典** | **浅拷贝** |


## 2.3 删除 (Deletion)

| 方法 | 说明 | 返回值 | 拷贝/引用类型 |
| :--- | :--- | :--- | :--- |
| **`del d[key]`** | 删除指定键的键值对。**若键不存在则报错 `KeyError`** | - | 原地修改 |
| **`.pop(k[, d])`** | 移除键 $k$ 并返回其对应的值。若 $k$ 不存在则返回默认值 $d$ | 被删除的值 | 原地修改 |
| **`.popitem()`** | 移除并返回最后一对插入的 `(key, value)` 元组 | `(key, value)` | 原地修改 |
| **`.clear()`** | 清空字典所有元素 | `None` | 原地修改 |



### 2.4 查找与成员检查 (Lookup)

由于字典是按键索引的，其查找性能极高。

#### 2.4.1 访问方式
* **`d[key]`**：直接访问。若键不存在会触发 `KeyError`。

!!! warning
    * **`.get(key, default)`**：安全访问。若键不存在则返回 `None` 或指定的 `default` 值。
    * **`.setdefault(key, default)`**：若键存在则返回其值；若不存在则插入 `key: default` 并返回 `default`。

#### 2.4.2 成员检查
* **`key in d`**：检查某个**键**是否存在于字典中（注意：不检查值）。
* **`key not in d`**：检查某个键是否不在字典中。

```python
info = {"id": 101, "status": "active"}
# 推荐写法
status = info.get("status", "unknown") 
```


## 3 视图对象 (View Objects)

字典提供三个动态视图方法，它们反映了字典的最新状态：

| 方法 | 说明 | 返回内容类型 |
| :--- | :--- | :--- |
| **`.keys()`** | 获取所有键的视图 | `dict_keys` |
| **`.values()`** | 获取所有值的视图 | `dict_values` |
| **`.items()`** | 获取所有 `(键, 值)` 元组的视图 | `dict_items` |

!!! info "视图的动态性"
    这些视图对象不是列表，而是“窗口”。如果原字典发生了改变，视图的内容会实时同步变化，且不占用额外的内存副本。


## 4 内存机制与性能

### 4.1 复杂度对比表

| 操作 | 复杂度 | 性能提示 |
| :--- | :--- | :--- |
| **键查找 `d[k]`** | $O(1)$ | 极快，不受数据规模影响 |
| **插入/修改** | $O(1)$ | 恒定时间 |
| **删除** | $O(1)$ | 恒定时间 |
| **遍历** | $O(n)$ | 线性时间 |

### 4.2 紧凑字典 (Compact Dict)
自 Python 3.6 起，字典采用了一种更紧凑的内存布局。它维护一个连续的数组来存储条目，并使用一个较小的哈希索引表。这减少了内存占用，并使字典能够记住插入顺序。



## 5 dict 的其他函数与方法

除了基础的增删改查外，Python 还提供了一些内置函数和辅助方法，用于高效地处理字典数据。

### 5.1 函数 (Built-in Functions)

这些函数通常将整个字典作为参数传入，用于获取字典的整体特征或进行序列化转换。

| 函数 | 说明 | 返回值 | 复杂度 |
| --- | --- | --- | --- |
| **`len(d)`** | 计算字典中键值对的总数 | 整数 (int) | $O(1)$ |
| **`list(d)`** | 将字典的所有**键**转换为列表 | 键列表 | $O(n)$ |
| **`sorted(d)`** | 对字典的**键**进行排序 | 排序后的键列表 | $O(n \log n)$ |
| **`any(d)`** | 检查字典中是否至少有一个键为真 (True/非空) | 布尔值 | $O(n)$ |
| **`all(d)`** | 检查字典中是否所有键都为真 | 布尔值 | $O(n)$ |

```python
info = {"id": 1, "status": "active", "tag": None}

# 获取长度
length = len(info)  # 3

# 排序键
sorted_keys = sorted(info)  # ['id', 'status', 'tag']

# 检查布尔值（只要有一个键不为空/0/False即为True）
has_content = any(info)  # True

```

### 5.2 方法 (Instance Methods)

这里补充一些在特定场景下非常有用的实例方法。

#### 5.2.1 `fromkeys()`

这是一个**类方法**，用于从序列（列表、元组等）快速初始化一个具有相同初始值的字典。

```python
# 语法：dict.fromkeys(iterable, value=None)
keys = ['name', 'age', 'city']
new_user = dict.fromkeys(keys, "Unknown")

print(new_user)
# 输出: {'name': 'Unknown', 'age': 'Unknown', 'city': 'Unknown'}

```

!!! warning "浅拷贝陷阱"
    如果 `fromkeys` 的默认值是一个**可变对象**（如列表），那么所有键都将指向**同一个内存地址**的列表。修改其中一个，所有键对应的值都会改变。

#### 5.2.2 `reversed()`

自 Python 3.8 起，由于字典保证了插入顺序，你可以使用内置的 `reversed()` 函数对字典的**键**进行反向迭代。

```python
d = {"a": 1, "b": 2, "c": 3}
for key in reversed(d):
    print(key, end=" ")
# 输出: c b a 

```

#### 5.2.3 方法汇总表（补充）

| 方法 | 说明 | 应用场景 |
| --- | --- | --- |
| **`d.get(k, default)`** | 获取键 $k$ 的值，不存在则返回默认值 | 避免 `KeyError` 的首选方案 |
| **`d.setdefault(k, default)`** | 获取值，若不存在则**插入**该键值对 | 简化“查无则增”的逻辑 |
| **`__contains__(k)`** | 底层方法，对应 `k in d` 语法 | 成员关系判断 |

!!! info "关于 **missing** 方法"
    在进阶开发中，你可以通过继承 `dict` 并实现 `__missing__(self, key)` 方法。这样当访问不存在的键时，字典会执行你定义的逻辑（如自动创建条目或记录日志），而不是抛出错误。




## 注意事项

1. **键的不可变性**：一旦使用对象作为键，就不应修改该对象的值（如果它是元组）。如果对象的哈希值改变，将无法再从字典中找回该键。
2. **避免遍历时修改**：在遍历字典视图时尝试添加或删除元素会触发 `RuntimeError: dictionary changed size during iteration`。
    * **正确做法**：`for k in list(d.keys()):` (先将键转为列表备份)。
3. **字典作为计数器**：对于频繁的初始赋值操作，建议使用 `collections.defaultdict` 以简化 `if key not in d` 的判断逻辑。
