## 引言
!!!
    OpenAI家的目前产品大致可以分成下面2类，每一类还有不同的存在形式
- **ChatGPT语言大模型：**
    * 官方网页端
    * Windows 官方桌面客户端
- **Codex：**
    * Windows 官方桌面客户端
    * CLI命令行端
    * VS code中的插件

## 1. ChatGPT 官方网页端

* **产品名称：** ChatGPT Web
* **形式：** **网页端**（Web 浏览器）
* **下载方法：** **无需下载**。在电脑浏览器中直接访问官方唯一主站：`chatgpt.com`，登录个人或 Pro 账号即可。
* **常用用处：**
* **深度推理与科学计算：** 网页端提供完整的 Frontier 旗舰模型控制，你可以自由调整模型的“思考时间（Thinking-time）”。遇到高难度的算法推导、复杂的空间数据处理逻辑或科研瓶颈时，让模型“多想一会儿”能换取极高正确率的深度正解。
* **通用生产力：** 多语种文献翻译、学术论文大纲撰写、图片商业设计（DALL·E）以及最新的个人理财看板分析。




## 2. ChatGPT Windows 官方桌面客户端

* **产品名称：** ChatGPT Windows Desktop App
* **形式：** **桌面独立 App**（后台常驻运行）
* **下载方法：**
1. 直接在 Windows 自带的 **Microsoft Store（微软应用商店）** 中搜索 “ChatGPT” 免费一键下载安装。
2. 或者访问 OpenAI 官网下载官方提供的 `MSIXBUNDLE` 桌面安装包。


* **常用用处：**
* **无缝并行工作（Alt + Space）：** 按下快捷键可以在屏幕中央唤出一个轻量级伴随窗口。你在用 VS Code 敲代码或用专业 GIS 软件跑数据时，可以不切窗口直接让它帮你查参数或查报错。
* **Canvas（画布）协作：** 自动开启分屏。左边聊天引导，右边高亮显示长代码或文本。你可以直接在右侧画布里让它行内重构代码、添加注释或一键 Debug。
* **高清多模态：** 直接将报错截图或学术图表拖进客户端，进行极速的视觉解析。同时支持高级语音模式（Advanced Voice Mode），可以戴着耳机和它口头探讨逻辑思路。


## 3. OpenAI Codex 电脑桌面端

* **产品名称：** OpenAI Codex 桌面客户端 (Codex Desktop)
* **形式：** **独立的图形化桌面软件 (Windows / macOS App)**
* **下载方法：**
* **方法一：** 打开 Windows 自带的 **Microsoft Store（微软应用商店）**，直接搜索 “Codex” 即可找到由 OpenAI 官方上架的桌面 App 并免费安装。
* **方法二：** 访问 OpenAI 官网 Codex 专题发布页进行下载。


* **常用用处：**
* **可视化 Diffs 与代码审查：** 提供直观的高亮分屏对比面板（类似 Git 冲突对比），让你在电脑屏幕上一眼看清智能体帮你重构、改写或优化的本地代码变动。
* **安全沙箱与权限管理：** 在图形化界面里提供可视化的安全控制面板，允许你一键勾选和管理智能体的本地文件夹读写、系统终端调用以及计算机使用（Computer Use）的操控权限。


## 4. OpenAI Codex CLI

* **产品名称：** OpenAI Codex CLI (命令行工具)
* **形式：** **终端命令行工具 / TUI（终端用户界面）**
* **下载方法：**
* **安装方法：** 确保电脑已配置好 Node.js 环境，在系统的命令提示符（CMD）或 PowerShell 中执行全局安装指令：`npm i -g @openai/codex`


* **常用用处：**
* **自动化无人值守（exec 模式）：** 支持通过 `codex exec "指令"` 让智能体在后台静默运行。非常适合处理大批量的本地数据跑批、自动化脚本监控、重度算法文件的批量重构或长周期的本地模型跑数任务。
* **轻量化终端交互：** 在终端输入 `codex` 可直接拉起半图形化的 TUI 界面，完全不占用重度图形资源，与本地的 Git、SSH 远程环境完美融合，用完即走。


## 5. Codex 的 VS Code 插件

* **产品名称：** OpenAI Codex for VS Code
* **形式：** **IDE 编辑器扩展插件 (VS Code Extension)**
* **下载方法：**
* **安装方法：** 打开 Visual Studio Code，点击左侧导航栏的 **Extensions（插件市场）** 图标，在搜索框中输入 **“OpenAI Codex”**，点击 Install 一键安装。


* **常用用处：**
* **全局上下文实时同步（Auto Context）：** 自动与你本地常驻的 Codex CLI 或桌面端进行联动。只要检测到你在 VS Code 中打开或切换特定的代码文件，底层的 Codex 就能瞬间感知当前的完整项目上下文。
* **行内原生协作：** 无需跳出当前的编码视窗，直接在代码行内通过快捷键呼唤 Codex，针对当前编写的函数、算法逻辑进行高精准度的就地补全、添加标准注释或针对报错信息进行原地 Debug。



## 其他： OpenAI 官方开源模型 (gpt-oss-20b)

* **产品名称：** gpt-oss-20b 模型（官方开源权重）
* **形式：** **本地可执行模型权重**（完全离线运行）
* **下载方法：**
1. 通过开源社区 **Hugging Face** 或 **GitHub** 的 OpenAI 官方发布页免费下载 `gpt-oss-20b` 的模型权重文件。
2. 配合电脑本地的开源大模型运行包（如 **Ollama** 或 **LM Studio**）在本地 CMD 中一键加载运行。


* **常用用处：**
* **纯离线与隐私数据安全：** 因为你的拯救者 Y9000P 拥有强大的标压处理器、大容量内存（16GB+）以及 NVIDIA RTX 独立显卡（自带充足显存），这套配置刚好可以**完美、丝滑地在本地白嫖运行**这款官方开源模型。
* **核心资产处理：** 当你有一些完全不能联网、涉及绝对隐私的本地科研数据资产、私人 Markdown 笔记库或者未公开发表的代码时，直接断网让本地的 gpt-oss 帮你分析和生成，速度极快且绝无数据泄露风险。
