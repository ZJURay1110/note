# Anthropic家族产品

*本人是在windows电脑上进行相关的安装和各种操作，注意甄别*

---

## 引言

!!!
    Anthropic（通常习惯称为 Claude 家族）家的目前产品大致可以分成下面3类，每一类包含不同的存在形式，并且与下文的详细介绍保持一一对应：

* **Claude 通用智能体与办公自动化：**
* Claude 官方网页端
* Claude Windows 官方桌面客户端


* **Claude Code 智能体编程平台：**
* Claude Code 电脑桌面端
* Claude Code CLI 命令行端


* **Anthropic 开发者与浏览器生态：**
* Anthropic Console 网页工作区
* Claude in Chrome 浏览器扩展插件



## 1. Claude 官方网页端

* **产品名称：** Claude Web
* **形式：** **网页端**（Web 浏览器）
* **下载方法：** **无需下载**。在电脑浏览器中直接访问官方唯一主站：`claude.ai`，登录账号即可。
* **常用用处：**
* **顶尖长文本与多模态分析：** 拥有极强的超长上下文理解能力（Context Window）。支持对代码库文档、长篇科研论文或行业报告进行多模态深度透视。
* **分屏工件交互（Artifacts）：** 当让它编写前端页面、交互式图表、小型游戏或算法流程图时，网页端右侧会自动弹出独立的展示画布（Artifacts 视窗），允许你直接在线预览和交互，无需复制到本地运行。
* **专属项目知识库（Projects）：** 允许用户针对特定任务（如某个 GIS 开发课题或神经网络调试项目）建立独立的 Projects 空间，将常用的参考代码和固定 Prompt 锁死在里面，进行极其精准的垂直领域对谈。

## 2. Claude Windows 官方桌面客户端

* **产品名称：** Claude for Windows
* **形式：** **桌面独立 App**（后台常驻运行）
* **下载方法：** 访问官方下载主页：`claude.ai/download`，点击选择 Windows 版本即可下载对应的桌面客户端安装包一键部署。
* **常用用处：**
* **系统级全局无缝呼出：** 支持 Windows 快捷键瞬间唤醒，不需要频繁切换浏览器。支持直接拖拽本地代码、文档和高清截图进行快速解析。
* **自动化办公与具身操作（Claude Cowork / Computer Use）：** 内置强大的“具身智能”交互能力。针对日常办公推出免代码的 Claude Cowork，你可以将一整个杂乱的本地文件夹丢给它，让它自主在后台翻阅应用程序、提取多源数据、对大量结构化或非结构化文件进行重命名、去重与总结汇报。

## 3. Claude Code 电脑桌面端

* **产品名称：** Claude Code 桌面客户端 (Claude Code Desktop App)
* **形式：** **独立的图形化开发桌面软件 (Windows / macOS App)**
* **下载方法：** 访问官方开发者专属主站：`code.claude.com`，或在其官方文档中直接选择 Windows (x64) 独立安装包进行免费下载与配置。
* **常用用处：**
* **多任务并行智能体编排（Parallel Orchestration）：** 专为工程级并发开发的全新形态。提供图形化的多任务侧边栏，支持同时拉起多个并行的智能体工作流（例如让 AI 在后台重构一个模块的同时，启动另一个会话去跑另一套测试逻辑）。
* **全功能轻量轻度 IDE：** 自带直观的代码高亮、Diff 对比面板（一键批准或驳回代码修改）、内置集成终端以及云端沙箱隔离运行模式（Cowork 模式），让自动化开发完全不抢占本地硬件性能。

## 4. Claude Code CLI

* **产品名称：** Claude Code CLI (命令行工具)
* **形式：** **终端命令行工具 / TUI（终端用户界面）**
* **下载方法：**
* **安装方法：** 确保电脑已配置好基础的 Node.js 环境，在系统的命令提示符（CMD）或 PowerShell 中执行全局一键安装指令：`npm install -g @anthropic-ai/claude-code`，随后在终端输入 `claude` 即可拉起。
* **常用用处：**
* **全自主 Agentic 闭环开发：** 它是目前极强的终端原生 AI 队友。进入项目文件夹输入 `claude` 之后，它能够全自主阅读整套代码库架构、跨多个文件进行大面积重构、自动在终端运行测试命令并捕捉报错日志、陷入自我分析与修复循环，直到把完整的 Commit / Pull Request 交付给你。
* **接管本地复杂工具链：** 开发者无需死记硬背 Git 的合并冲突命令、Docker 的复杂配置或是各种编译指令。直接用自然语言交代意图，它会自动解析项目根目录下的 `CLAUDE.md`（记忆上下文规则文件），拼接并完美执行本地一切命令。

## 5. Anthropic Console 网页工作区

* **产品名称：** Anthropic Console
* **形式：** **网页端高级开发者控制台 / 提示词实验室**
* **下载方法：** **无需下载**。直接在电脑浏览器访问：`console.anthropic.com` 即可。
* **常用用处：**
* **原生 Raw 模型调测（Workbench）：** 允许开发者在工作台中不经过任何上层封装，直接调用原生的 Claude 3.5 Sonnet / Claude 4 等底层引擎，精细调整 Temperature（随机度）等参数以捕获最纯粹的推理结果。
* **一键提示词转代码（Prompt Generation）：** 在该工作台里用自然语言调教和优化好提示词后，可以使用内置的“生成代码”功能，一键将其导出为 Python、TypeScript 或是 C# 等后端 API 调用的原生标准代码块。

## 6. Claude in Chrome 浏览器扩展插件

* **产品名称：** Claude in Chrome (Beta)
* **形式：** **浏览器扩展插件 (Browser Extension)**
* **下载方法：**
* **安装方法：** 打开 Google Chrome 或基于 Chromium 内核的 Edge 浏览器，访问 **Chrome Web Store（谷歌应用商店）**，搜索 “Claude in Chrome”，点击“添加到 Chrome”一键安装并登录付费个人/团队账号。
* **常用用处：**
* **录制并自动化复杂网页工作流（Record a workflow）：** 支持在侧边栏常驻。你可以在浏览器里手动操作一次繁琐的跨多标签页收集信息、数据录入或报表填写，让它“录制”学会后，Claude 便能完全自主在后台模拟点击完成高重复性工作。
* **与本地开发终端联动（Build-Test 协同）：** 完美连通本地的 Claude Code 体系。在 CLI 或桌面端编译好前端代码后，该扩展能全自动接管浏览器端的端到端测试，实时读取 Chrome 控制台日志（Console logs）并将 Bug 反馈给底层的编程智能体进行自我迭代。
